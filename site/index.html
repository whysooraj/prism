The Context Vacuum

Why Raw HTML and Downscaled Screenshots Blind AI Models

Standard LLM toolkits provide agents with low-fidelity approximations that force models to hallucinate layout dimensions and read codebases through unindexed string search.

Web Inspection
Uncomputed HTML & Vision Screenshots
  • • Raw DOM text omits computed CSS cascade, box-model rects, and render coordinates.
  • • Screenshots compressed to 1024px blur micro-typography, subpixel padding, and borders.
  • • Vision models cannot mathematically measure WCAG contrast ratios or 8pt grid alignment.
Deterministic Headless Layout Extraction
  • • Extracts real computed values directly from Chromium layout engine.
  • • Generates 2D ASCII spatial radars and exact box models: padding, margin, bounds.
  • • Computes exact WCAG AAA color contrast ratios and flags layer occlusion collisions.
Codebase Navigation
Full-File Dumps & Naive Grep
  • • Dumping entire files burns thousands of context tokens and triggers attention drift.
  • • Text regex cannot trace AST relationships, inheritance, or route decorators.
  • • Agents cannot deduce which source file produced a rendered DOM element.
AST Symbol Indexing & Line-Sliced Retrieval
  • • Fast tree-sitter AST parser extracts function signatures, classes, and exported routes.
  • • get_file delivers line-sliced fragments with line numbers, eliminating context pollution.
  • • find_ui_source correlates rendered DOM tags and text directly to JSX/TSX source lines.
System Design

Tri-Core Intelligence Pipeline

Prism operates as a high-throughput bridge connecting external AI agents to deterministic web runtime and AST repository indexes.

01

MCP Transport Layer

stdio / SSE / REST

Exposes standard Model Context Protocol tools to agents like Antigravity, Claude Code, Cursor, and OpenClaw, with zero agent-side modifications.

02

Web Inspection Pipeline

Headless Chromium

Navigates target URLs, evaluates computed styles, runs WCAG audits, computes 2D spatial radars, and renders vector wireframe SVGs.

03

Correlation & Verification Engine

DOM <-> Source Matcher

Maps rendered selectors to code lines with find_ui_source, and computes differential layout regressions across state transitions with verify_change.

04

AST Repository Pipeline

In-Memory Tree-Sitter & Git

Indexes symbols, maps caller/callee graphs, calculates blast radius up to depth 3 with trace_impact, and provides line-sliced surgical code slices.

Deterministic API

13 Model Context Protocol Tools

Categorized tools exposed via JSON-RPC stdio, Server-Sent Events, and REST.

Web Inspection & Layout
inspect_website
url, viewport?, includeWireframeSvg?, includeA11y?, allowLocalhost?
Extracts full layout tree, computed box models, design tokens, WCAG contrast audits, and vector wireframe SVGs.
inspect_page
url?, compact?, viewport?
Inspects the active session app with token-efficient output options for iterative agent loops.
capture_screenshots
url, allowLocalhost?
Captures synchronized dual viewports: Desktop (1440x900) and Mobile (390x844).
Source Correlation & Verification
find_ui_source
projectPath, selector?, tag?, textSnippet?, currentRoute?
Correlates rendered DOM nodes directly to JSX/TSX components and exact line numbers.
verify_change
before, after, beforeUrl?, afterUrl?
Compares layout states before and after code edits, validating resolved bugs and flagging layout regressions.
get_context
selector?, textSnippet?, tag?, urlOrRoute?, inspectionResult?
Unified token-efficient payload combining element bounding box, layout defects, source candidates, and blast radius.
connect_project
repoPath, appUrl?, branch?
Binds a local repository path to a running application URL to maintain an active inspection session.
Codebase & AST Intelligence
index_repository
urlOrPath, branch?, authToken?
Performs ephemeral repository acquisition, parses AST symbols, builds file trees, and extracts routes.
search_codebase
query, kind?, limit?
Executes structural AST searches for functions, classes, interfaces, and API endpoints.
get_file
filePath, startLine?, endLine?
Surgically retrieves precise file line ranges (e.g. lines 40-75) without polluting context with full files.
trace_symbol
symbolName
Traces definitions, direct importers, re-exports, callers, callees, and route handlers for a target symbol.
trace_impact
target, repoIdentifier?
Calculates direct and transitive blast radius, affected HTTP endpoints, and assign risk levels (LOW/MEDIUM/HIGH).
explain_architecture
none
Summarizes tech stack, package dependencies, main entry points, and structural directory taxonomy.
